# CONTENT_STRATEGY.md — AnonTrove Editorial & Product Content Strategy
**Brand:** AnonTrove (`https://ebook-sandy-chi.vercel.app/`)  
**Mission:** High-Utility, Verified Technical Knowledge with Zero Fluff  

---

## 1. Editorial Integrity & Anti-Hallucination Directives

1. **Authentic Attribution Mandate:**
   - Always preserve the genuine original author and publisher names (e.g. Vivek Chadha, Joshua J. Drake, Zebra Learn, Wiley, O'Reilly).
   - Never replace recognized historical authors with "AnonTrove Editorial Guild".
   - If an author is genuinely unknown, denote as "Independent Technical Author" or omit author schema to prevent misleading crawlers.

2. **Truthful Specification Verification:**
   - Display verified page counts and file sizes based on actual stored document bytes.
   - Never generate simulated aggregate ratings, review stars, or fake testimonials.
   - Clearly delineate between published DRM-free books and student lecture notes.

3. **Content Structure for Product Pages (`/book/[slug]`):**
   - **Executive Summary:** What the reader will learn in 2-3 concise sentences.
   - **Table of Contents (Sample):** Verified chapter breakdown.
   - **Technical Specifications:** Accurate file format (PDF/EPUB), file size (MB), pages count, and language.
   - **Authentic Sample Excerpt:** First 1-2 pages of authentic reading material.
   - **Related Learning Resources:** Cross-links to 4 related titles in the same topic.

---

## 2. Category Hub Architecture

Each of the 10 authoritative category pages (`/category/[slug]`) follows a high-converting, search-engine-friendly structure:
1. **Semantic H1 Heading:** Category Name with curated count badge.
2. **Editorial Introduction:** 100-150 words summarizing the field, practical applications, and who should read it.
3. **Subcategory Tags:** Visual filter pills directing users to specific sub-disciplines.
4. **Curated Showcase:** Grid of top-rated and demanded titles in that category.
5. **AEO / Answer-Engine FAQ:** 2-3 verified questions with clear answers for citation by AI search engines.
