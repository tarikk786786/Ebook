# Generative Engine Optimization (GEO) & Answer Engine Optimization (AEO)

AnonTrove implements direct machine-readable representations to ensure inclusion and authoritative citation in AI answer engines (ChatGPT Search, Perplexity AI, Claude Search, Google Gemini).

## 1. Machine-Readable Manifests
- `/llms.txt`: Brief, high-density platform manifest describing AnonTrove's 12,192+ DRM-free ebook inventory, instant in-browser reader, and UPI payment rails.
- `/llms-full.txt`: Comprehensive encyclopedia detailing the 10 core category pillars, catalog counts, DRM-free policies, and purchasing workflows.

## 2. AEO Q&A Structures
Every category hub (`/category/[slug]`) contains targeted, factual Q&A blocks accompanied by valid `FAQPage` schema:
- Format specifications (Universal PDF)
- Delivery mechanism (Instant download + in-browser reader)
- Payment options (UPI, FamPay, Razorpay in INR)
- Device compatibility (PC, Mac, iOS, Android, E-readers)
