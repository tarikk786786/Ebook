# AnonTrove Autonomous SEO Agent Operational Guide

## Overview
The platform operates 22 autonomous specialized agents configured in `/agents/`:
1. `seo_orchestrator`: Pipeline orchestrator.
2. `technical_seo_agent`: HTTP headers, redirects, crawl budget.
3. `website_crawler_agent`: Linkinator & Playwright deep crawls.
4. `keyword_research_agent`: Ebook transaction search queries.
5. `serp_analysis_agent`: SERP feature monitoring.
6. `competitor_intelligence_agent`: Ethical market gap benchmarking.
7. `product_seo_agent`: 12,192+ book detail metadata hygiene.
8. `category_seo_agent`: 10 topical category hubs.
9. `content_research_agent`: Syllabus and course topics.
10. `content_writing_agent`: Factual metadata copywriter.
11. `content_quality_agent`: Anti-hallucination gatekeeper.
12. `schema_agent`: JSON-LD structured data validator.
13. `sitemap_agent`: XML sitemap maintenance.
14. `internal_linking_agent`: Internal PageRank distribution.
15. `backlink_research_agent`: Referral citations.
16. `geo_agent`: Generative Engine Optimization.
17. `aeo_agent`: Answer Engine Optimization.
18. `local_seo_agent`: Regional INR currency and UPI rails.
19. `ecommerce_seo_agent`: InStock availability schema.
20. `analytics_agent`: Privacy-first metrics.
21. `performance_agent`: Core Web Vitals guardian.
22. `seo_qa_agent`: Automated regression test runner.

## Execution via Admin Dashboard
Administrators can trigger agent actions on-demand via `/admin/seo`.
